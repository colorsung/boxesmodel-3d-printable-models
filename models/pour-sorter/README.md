## Printing and assembly

- The floor drops toward the narrow mouth, so parts pour out easily when it is tilted; not an automatic gravity feed mechanism.
- A 1 mm lip at the pour spout stops small items sliding out when laid flat. Print base down; granule flow is still to be measured.
- Import at millimeter scale. Check your build volume, orientation, overhangs, supports and mating clearances in the slicer.
