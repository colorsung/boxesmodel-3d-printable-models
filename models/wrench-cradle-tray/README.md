## Intended use

- Wrenches; size slots for handle thickness plus clearance, not nominal jaw size. Support straight sections; check drawer and adjacent head space. Tools extend beyond printed bounds; no clamp or inversion retention.

## Printing and assembly

- Wrenches stand on edge across the two matching rows of slots and go in and out from above; both rows print in one piece with the base; no assembly needed.
- Slot width is the actual handle thickness plus access allowance, not the wrench's nominal opening size; linear taper of width from first to last; can be set equal. The support center span should fall on the straight shank section the tool can rest on.
- Long tool heads can pass over the low edge; the print envelope excludes tools; separately check drawer space and the width of neighboring tool heads; no clamping or anti-tip retention.
- Import at millimeter scale. Check your build volume, orientation, overhangs, supports and mating clearances in the slicer.
