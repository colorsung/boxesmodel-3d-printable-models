## Printing and assembly

- The central compartment holds supplies, and the petal compartments sort by color or step; the number of outer compartments, central capacity and waist adjust together, with dividers joined to a shared floor.
- One-piece print. Outer length and width control the actual envelope; the clear width at the petal tips changes with the compartment count and waist.
- Import at millimeter scale. Check your build volume, orientation, overhangs, supports and mating clearances in the slicer.
