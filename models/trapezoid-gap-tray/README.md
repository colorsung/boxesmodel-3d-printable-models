## Printing and assembly

- The narrower end faces the entrance of the angled space; a long middle slot holds slender tools, with segments on both sides by use.
- One-piece structure; outer length means the maximum rear width, and outer width means the front-to-back depth; the front end width is set separately.
- Import at millimeter scale. Check your build volume, orientation, overhangs, supports and mating clearances in the slicer.
