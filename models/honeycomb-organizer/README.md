## Printing and assembly

- Each hexagonal compartment has its own walls and floor on one shared base plate; not a removable module or standard interface.
- Print base down, leaving gaps between compartments; test-print to check cleaning and fit with your actual small items first.
- Import at millimeter scale. Check your build volume, orientation, overhangs, supports and mating clearances in the slicer.
