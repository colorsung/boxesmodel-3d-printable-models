## Printing and assembly

- Each level uses the same four corner locating feet and top seats; lift 4 mm to separate; remove level by level when carrying; locating is not locking.
- Only low cross dividers; above the front stop the full access path is kept; items must be lifted over the front edge.
- Total height includes the feet; only levels generated with the same parameters stack; test-print to check load-bearing, stability and fit first.
- Import at millimeter scale. Check your build volume, orientation, overhangs, supports and mating clearances in the slicer.
