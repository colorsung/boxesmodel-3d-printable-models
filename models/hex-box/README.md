## Printing and assembly

- Length measures the left and right points, width the two parallel edges; after adjusting length and width independently it may no longer be a regular hexagon.
- The lid locates with a fixed 0.4 mm single-side clearance and 3 mm insertion; pairs only within this set.
- Box base down; tray lid locating face down; check supports for the lid rim overhang when slicing. Check the real tightness before use.
- Import at millimeter scale. Check your build volume, orientation, overhangs, supports and mating clearances in the slicer.
