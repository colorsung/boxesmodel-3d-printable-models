## Printing and assembly

- Back row dividers have staggered index tabs for your own labels; front finger grooves make cards easy to take.
- Card size is not fixed; leave allowance based on the measured size with sleeves; base down; check the thin ears when slicing.
- Import at millimeter scale. Check your build volume, orientation, overhangs, supports and mating clearances in the slicer.
