## Printing and assembly

- Lift-off box lid; not a clip, seal or load-bearing latch. Only fits boxes from the same set.
- Flip the box lid 180° in the slicer so the flat face is down; box base down.
- The locating specification is fixed; test-print with your actual printer and material to check the real fit.
- Import at millimeter scale. Check your build volume, orientation, overhangs, supports and mating clearances in the slicer.
