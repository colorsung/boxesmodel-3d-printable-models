## Printing and assembly

- Cables coil loosely around a post inside the compartment, with ends led out of the front opening; choose the size by your actual cable diameter and bend radius.
- For sorting idle cables; print base down.
- Import at millimeter scale. Check your build volume, orientation, overhangs, supports and mating clearances in the slicer.
