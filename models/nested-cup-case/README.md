## Printing and assembly

- Each cup can be used on its own; nest them from largest to smallest, with each inner cup's base resting on the solid floor of the outer cup.
- A front grip makes each cup easy to lift, with 0.4 mm clearance per side; usable storage height is measured to the lower edge of the grip. No seal or latch.
- Print base down; test-print to check actual friction and grip feel first.
- Import at millimeter scale. Check your build volume, orientation, overhangs, supports and mating clearances in the slicer.
