# Comb Tooth Relief Lying Box

Rest a comb's spine on ledges with teeth clear in a deep slot; grip at both ends. Adjust tooth-slot width, spine space and clearance depth.

## Intended use

- Combs; the spine must be wider than the tooth slot. Allow tip clearance based on root-to-tip length.

## Printing and assembly

- One-piece, no hardware. The spine can rest on the shoulder when it is wider than the tooth gap; measure the length from tooth root to tooth tip first so the tips have allowance.
- Units are millimeters; matching parts use files generated in the same export. Set clearance by your items' maximum size and leave room to take them in and out.
- Check orientation and supports before printing, and test-print key mating parts first.
- Import at millimeter scale. Check your build volume, orientation, overhangs, supports and mating clearances in the slicer.
